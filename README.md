# Verified repository archive

Open [the archive index](archive/README.md) for issue, pull-request and release history, or [the manifest](archive/manifest.json) for source mappings and SHA-256 checksums.

For large attachments, run `python tools/restore_archive.py archive restored-files` after cloning this branch. The restored files are verified against their original whole-file hashes.

Source implementation and usage: https://github.com/nexicturbo/THE-ERROR-IS-THE-MESSAGE/tree/main/docs
