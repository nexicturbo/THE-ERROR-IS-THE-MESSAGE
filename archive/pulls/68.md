# Add a mobile-triggered repository archive with verified attachment caching

https://github.com/attogram/THE-ERROR-IS-THE-MESSAGE/pull/68

Implements #60 with a phone-triggered Actions workflow, a standard-library Python exporter, and a dedicated archive branch. It saves issue and PR conversations, reviews, releases, tags and uploaded files, with readable pages and the original JSON. Re-runs verify cached files by SHA-256 before reusing them.

Validation: 14 local tests pass, including two real pushes to a temporary Git repository that preserve the source checkout and archive history. The live API run collected 60 issues, 6 PRs, 168 comments, 4 releases and 4 tags. Attachment validation remains partial: one example URL returns 404 and one PDF is excluded from this verification. The hosted workflow demonstration is still pending.

Run it from **Actions → Save repository conversations and attachments → Run workflow**. Local instructions are in `ARCHIVE_TOOL.md`.
