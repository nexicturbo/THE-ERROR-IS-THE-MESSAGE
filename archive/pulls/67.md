# Archive repository from mobile with verified attachments and hosted demonstration

https://github.com/attogram/THE-ERROR-IS-THE-MESSAGE/pull/67

For #60: a phone-triggered archive that preserves repository conversations, releases, and attachment bytes in a dedicated `repository-archive` branch.

The Python standard-library exporter paginates open and closed issues and PRs, discussion comments, reviews, inline review comments, PR commit comments, release notes/assets, tags, and generated release ZIP/TAR archives. Raw JSON and original source URLs are retained. Large media is split into parts of at most 40 MiB, with both part and whole-file SHA-256 verification; the archive includes an offline verification/restoration script.

The workflow runs tests, exports, verifies, and publishes using its automatic `GITHUB_TOKEN`. Publication uses a separate Git index and bounded upload batches, then advances the archive branch only after every file has arrived. No personal token, paid service, Git LFS, or Python package installation is needed. Failed API calls or real downloads keep the snapshot partial and prevent publication. Literal example paths such as `assets/xxxx` remain in the source text but are not treated as uploaded files.

Run from a phone: **Actions → Archive repository → Run workflow**. In this demonstration the output goes to my fork; after merging, running the workflow here writes the archive directly into this repository. Full instructions: [docs/REPOSITORY_ARCHIVE.md](https://github.com/dziurawiecwempe582-hub/THE-ERROR-IS-THE-MESSAGE/blob/codex/repository-archive/docs/REPOSITORY_ARCHIVE.md).
