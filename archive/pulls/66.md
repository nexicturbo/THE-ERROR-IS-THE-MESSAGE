# Add a resumable repository archive with checksummed media and manual Actions

https://github.com/attogram/THE-ERROR-IS-THE-MESSAGE/pull/66

Adds a dependency-free Python exporter and manual Actions workflow for #60. Issues, PR conversations/reviews, releases, tags, root-README text and GitHub-hosted media are preserved as JSON, readable pages and a checksummed URL-to-file manifest. The workflow commits the dump to a dedicated archive branch. Reruns reuse verified files; missing media and exhausted budgets remain explicit failures.
